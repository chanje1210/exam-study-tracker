시험 준비 트래커 사용법

시험 범위를 개념 공부와 문제 풀이로 나눠 기록하고, 과목별 진도와 D-day를 한눈에 보는 앱이에요.

  1. 과목 추가

    오른쪽 위 + 과목 추가를 눌러 과목명, 시험 날짜, 색을 정해요. 날짜를 넣으면 D-day가 나오고, 시험이 가까운 과목부터 보여요. 과목 이름·날짜를 바꾸거나 삭제하려면 카드의 ⚙︎를 눌러요.

  2. 공부할 항목 넣기

    과목 카드의 개념 공부 · 문제 풀이 탭을 골라 아래 입력칸에 항목을 추가해요. 예: 개념은 'Ch.3 화학 평형', 문제는 '연습문제 3장'.

  3. 진행도 기록

    항목 아래 초록 막대를 드래그해 0~100%로 기록해요. 다 끝냈으면 체크박스를 눌러 바로 100%로 만들 수 있어요(해제하면 0%).

  4. 가중치 상 · 중 · 하

    항목 앞의 중 버튼을 누를 때마다 중 → 하 → 상으로 바뀌어요. 중요하거나 분량이 많은 항목은 '상'으로 두세요. 진도 계산에서 상은 3배, 중은 2배, 하는 1배로 반영돼요.

  5. 진도는 이렇게 계산돼요

    개념·문제 진도 = 각 항목 진행도의 가중 평균
    과목 진도 = 개념 진도와 문제 진도의 평균
    전체 진도(맨 위) = 모든 과목 진도의 평균

  6. 항목 정리

    항목의 ✎로 이름 수정, ↑ ↓로 순서 변경, ✕로 삭제해요. 컴퓨터에서는 항목 이름을 더블클릭해도 수정돼요.

  7. 한눈에 보기 · 요약 화면

    위쪽 한눈에 보기에서 과목별 개념·문제 진도를 비교해요. 요약만 보기를 누르면 요약만 남아요. 링크 끝에 #widget을 붙여 홈 화면에 추가하면 요약 화면으로 바로 열려요.

  8. 저장 상태 확인

    기록은 자동 저장돼요. 오른쪽 위 표시를 확인하세요.

    • 서버에 저장됨: 내 계정에 저장돼서 다른 기기에서도 보여요. 다른 사람은 내 기록을 볼 수 없어요.
    • 이 기기 브라우저에만 저장: 브라우저 데이터가 지워지면 사라질 수 있어요.
    • 저장 권한 없음: 링크를 공유해 준 사람에게 '편집자' 권한을 요청하세요.

    혹시 모르니 가끔 백업 / 불러오기 → 복사로 기록을 메모 앱에 보관해 두면 안전해요.
